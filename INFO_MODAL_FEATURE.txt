💻 TECHNICAL IMPLEMENTATION
═══════════════════════════════════════════════════════════════════════════════

HTML STRUCTURE:
```html
<button id="infoBtn" class="info-btn" title="माहिती वाचा">ℹ️</button>

<div id="infoModal" class="modal">
  <div class="modal-content">
    <button id="closeModal" class="close-btn">&times;</button>
    <h2 class="modal-title">ℹ️ शेतकऱ्यांसाठी माहिती</h2>
    <!-- 7 sections with Marathi content -->
    <button id="closeBtn2" class="modal-button">बरोबर समजलं</button>
  </div>
</div>
```

CSS CLASSES:
  ├─ .info-btn - Button styling
  ├─ .modal - Container (hidden by default)
  ├─ .modal.active - Display when clicked
  ├─ .modal-content - White box with content
  ├─ .modal-title - Green title with green underline
  ├─ .modal-section - Each section (7 total)
  ├─ .warning-section - Yellow disclaimer box
  ├─ .modal-button - "बरोबर समजलं" button
  ├─ .close-btn - X button
  └─ @keyframes - Animations (fadeIn, slideUp)

JAVASCRIPT FUNCTIONALITY:
  ├─ infoBtn.addEventListener('click') - Open modal
  ├─ closeModal.addEventListener('click') - Close with X button
  ├─ closeBtn2.addEventListener('click') - Close with button
  ├─ infoModal.addEventListener('click') - Close if clicking outside
  ├─ document.addEventListener('keydown') - Close with Escape key
  ├─ classList.add('active') - Show modal
  ├─ classList.remove('active') - Hide modal
  ├─ body.style.overflow = 'hidden/auto' - Prevent/allow background scroll
  └─ All with smooth animations (0.3s ease transitions)
