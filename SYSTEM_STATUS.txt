🔧 TECHNICAL IMPLEMENTATION

VOICE CODE (JavaScript):
```javascript
function speakText(text) {
  if (!("speechSynthesis" in window)) {
    alert("⚠️ Your browser doesn't support voice");
    return;
  }
  
  const utter = new SpeechSynthesisUtterance(text);
  utter.lang = "mr-IN";      // Marathi language
  utter.rate = 0.85;         // Slow speed = clear
  utter.pitch = 1.0;         // Normal pitch
  utter.volume = 1.0;        // Full volume
  
  window.speechSynthesis.cancel();  // Stop previous
  window.speechSynthesis.speak(utter); // Play new
}
```

SERVICE WORKER (JavaScript):
```javascript
// Install: Cache all assets
self.addEventListener("install", e => {
  e.waitUntil(caches.open(CACHE).then(c => c.addAll(ASSETS)));
});

// Fetch: Network-first for API, Cache-first for static
self.addEventListener("fetch", e => {
  if (e.request.url.includes("/problems"))
    e.respondWith(fetch(e.request).catch(...)); // Network first
  else
    e.respondWith(caches.match(e.request).then(...)); // Cache first
});
```
