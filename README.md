# Organic Shet Doctor AI

सरळ, सेंद्रिय शेती सहाय्यक

## फोल्डर संरचना
```
OrganicShetDoctorAI/
├── backend/          # FastAPI सर्व्हर
│   ├── main.py       # एपीआय एंडपॉइंट्स
│   ├── database.py   # SQLite कनेक्शन
│   └── models.py     # पायडँटिक मॉडेल्स
├── frontend/         # HTML/CSS/JS ग्राहक
│   ├── index.html
│   ├── styles.css
│   └── script.js
├── db/
│   └── schema.sql   # डेटाबेस स्कीमा व नमुना डेटा
└── README.md
```

## SQLite स्कीमा व प्रारंभिक डेटा
`db/schema.sql` मध्ये दोन टेबल आहेत:
- `problem(problem_id, name, symptoms, cause)`
- `organic_solution(solution_id, problem_id, solution_name, ingredients, preparation, dosage, timing, warning)`

फायली चालवून डेटाबेस (`organic_shet.db`) तयार करा:
```bash
sqlite3 db/organic_shet.db < db/schema.sql
```

## बॅकएंड सेटअप
1. `python -m venv venv` आणि सक्रिय करा.
2. `pip install fastapi uvicorn pydantic`.
3. `uvicorn backend.main:app --reload`

एपीआय:
- GET `/problems` – सर्व समस्या मिळवा
- GET `/problems/{id}/solutions` – विशेष समस्येसाठी उपाय
- POST `/upload` – चित्र प्रकरणासाठी (501 सध्या)

## फ्रंटएंड वापरणे
ब्राउझरमधे `frontend/index.html` उघडा. मोबाइल-फर्स्ट डिझाइन आहे.

## सुरक्षित AI प्रॉम्प्ट (डेटाबेसपासून स्पष्टीकरणासाठी)
```
तुम्ही एक कृषी सहाय्यक आहात. शेती समस्यांची यादी SQLite डेटाबेसमधून वाचून,
प्रत्येक समस्येसाठी उपलब्ध असलेल्या सेंद्रिय उपायांचे चरणवार मार्गदर्शन मराठीत
काही शब्दात सांगा. केवळ डेटाबेसमधील घटक वापरा – नविन उपाय बनवू नका.
रसायन, ब्रँड किंवा बाजारातले उत्पादन कधीही सुचवू नका. उपाय फक्त नेम, लसूण,
मिरची, गोमूत्र, गोबर, राख, तुळशी व इतर घरी / शेतात उपलब्ध घटकांवर आधारित
असावेत. हे वैद्यकीय सल्ला नाही तर पारंपरिक मार्गदर्शन आहे, त्यामुळे सरळ,
सुरक्षित भाषा वापरा.
```


## टिप्पण्या
- सर्व मजकूर मराठीत सोप्या भाषेत लिहिला आहे. UI मधील बटणे मोठी आणि साधी आहेत.
- भविष्यात प्रतिमा विश्लेषण जोडा, डेटा वाढवा, व वापरकर्ता सुलभता सुधारा.
